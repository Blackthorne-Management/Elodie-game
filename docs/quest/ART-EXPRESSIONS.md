## How to make them

If you still have the character's original chat, use it and paste only the one-line ask. If not, open a **new chat**,
attach the character's **plain portrait** (the file named in the table, from `docs/quest/art-source/`), and paste this
prompt, with the expression filled in:

```
Same character as the attached portrait. Make the same head-and-shoulders portrait: the same face, the same clothes, the same framing, the same lighting from the upper left, the same hand-painted fantasy storybook style, and the same solid flat magenta background (#FF00FF) filling the whole square. Change only the expression: [EXPRESSION]. No text, no frame, no border, no other people.
```

Send them to me as they come. I size and check each one against the plain portrait, so the face never jumps.
