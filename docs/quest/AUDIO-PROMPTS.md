# Audio prompts: music for Pòdlimyè (Chapter 1)

The owner generates the music (Oct 16); Claude makes the sound effects in code. Settled style (SCHEDULE.md,
"Open decisions"): music in the style of each culture; for Pòdlimyè, twoubadou and kompa guitar for the city,
rara horns for the festival. Tone: a serious main story with comic companions.

**For every track:** instrumental only, no vocals, 16-bit retro game style (Super Nintendo era), a seamless
loop of about 60 to 90 seconds (except the victory fanfare). Send MP3 or WAV; upload to `docs/quest/audio/`
on GitHub with the file names below.
