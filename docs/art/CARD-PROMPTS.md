# Card art: 120 prompts

Each block is a complete prompt: paste one per image, in any chat, in any order. **Attach the board painting
(the map you made) to every prompt** as the style reference; that and the shared style line keep 120 pictures
looking like one set.

**What you're making:** the full card artwork, like a trading card. The painting fills the whole card. Later
we lay a PNG overlay on top of every card: the border, a title plate across the top, and a text box over the lower
part. So the art must have **no frame, no border, no title and no text**, and must leave room for those.

| | |
|---|---|
| **Size** | 1000 × 1400 (vertical, 5:7, standard trading-card shape) |
| **File name** | `card-<number>.png`, e.g. `card-1.png` for Royal Favor |
| **Layout** | Top 12%: calm background for the title. 15–60%: the main subject. Bottom 40%: the scene continues under the text box, with nothing important in it. |

```
┌────────────────────┐
│  (calm: title)     │  top 12%
│                    │
│   MAIN SUBJECT     │  15–60%
│                    │
│░░░░░░░░░░░░░░░░░░░░│
│░ scene continues ░░│  bottom 40%: text box goes over this
│░░░░░░░░░░░░░░░░░░░░│
└────────────────────┘
```

**Tips**
- Do a whole category in one chat ("Next one, same style and layout: …") so the look stays steady, and re-attach
  the map when you start a new chat.
- The 10 Elodie cards (marked ✦) show the goddess only as hands, an eye or a starry silhouette, so she never looks
  different from card to card.
- If a picture comes back with text or a frame, ask: *"Same picture, remove all text and any border."*
- If the subject sits too low, ask: *"Same picture, move the subject higher; keep the bottom part simple."*
