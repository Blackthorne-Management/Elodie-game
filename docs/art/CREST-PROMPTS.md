# House crests: 8 prompts

Each block is a complete prompt. Attach the board painting as the style reference, like the other art.

| | |
|---|---|
| **Size** | 1024 × 1024, square |
| **File name** | `crest-<house>.png`, e.g. `crest-brasador.png`, into `art/crests/` |
| **Background** | Transparent if your tool can do it; otherwise plain flat white. The game cuts the round medallion out either way. |
| **Where they appear** | The right-hand medallion on every character card, the pawns and crests in the app, and later the Grudge Tokens and owned tiles. |

**Tips**
- Make all eight in one chat ("Next crest, same style and size: …") so the rims and enamel match.
- Check each one shrunk to thumbnail size: the silhouette should still read at 32 px. If it doesn't, ask: *"Same crest, simpler and bolder, fewer details."*
- Hand Cards, Instants and Elodie cards have **no crest**: they're the shared deck and belong to no house.

**Brasador**  
`crest-brasador.png`
```
A round heraldic medallion emblem for a fantasy board game house: a bull's skull crowned with flame, above a branding-iron mark. Bold, clear silhouette in crimson, black and gold, set on an enamel disc with a thin gold rim, painted enamel-and-gold-leaf look. Centred, flat front view, the medallion filling about 90% of a square image, on a transparent background (or plain flat white if transparency isn't possible). Simple enough to read when shrunk to a tiny icon. Style: hand-drawn fantasy storybook illustration matching the attached map image — crisp dark ink outlines, warm painterly colour with soft shading, rich jewel tones, warm light from the upper left, clean readable shapes. Avoid: any text, letters, numbers, mottos or runes; banners, ribbons, shields or extra frames outside the round rim; real-world national or family coats of arms; watermarks or signatures; photorealism; 3D render look; anime or cartoon style.
```
